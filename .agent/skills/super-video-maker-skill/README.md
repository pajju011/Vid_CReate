# Super Video Maker Skill — Architecture & Directives

An end-to-end AI video production pipeline for agentic frameworks, combining code-driven video layouts, FFmpeg visual processing, and Whisper alignment.

## Core Modules
- **`FFMPEG_PLAYBOOK.md`**: Command-line visual compositing, PiP, audio normalization, and vertical format adaptation.
- **`REMOTION_VIDEO_GUIDE.md`**: React code-driven canvas layouts, kinetic text rendering, and spring-based animations.
- **`HOOK_PLAYBOOK_ARTICLE_SPRINT.md`**: Retention strategies and 3-second hook formulas.
- **`SPOKEN_VO_HUMANIZER.md`**: Voiceover cadence, pacing markers, and breath pauses.
- **`VIDEO_COPY_PLAYBOOK.md`**: High-conversion video script templates.
