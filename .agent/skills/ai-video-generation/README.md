# AI Video Generation Engine — Architecture & Model Guide

Unified procedural interface for 40+ generative video diffusion models, including Google Veo 3.1, Seedance 2.0, Wan 2.5, HappyHorse, and HunyuanVideo.

## Core Modules
- **`SKILL.md`**: Master procedural video generation directives, resolution specs, and quality gates.
- **`INSTRUCTIONS.md`**: Model selection matrices, cinematic prompt expansion templates, and lipsync parameter guides.
